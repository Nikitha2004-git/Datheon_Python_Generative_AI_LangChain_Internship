# Sample documents

Small, safe files you can use to try the app right away. All three were written
for this project (the leave policy is a fictional company) and contain no
confidential information. You may use and redistribute them freely.

| File | Good for testing |
|------|------------------|
| `solar_energy_basics.txt` | science-style Q&A |
| `company_leave_policy.txt` | factual lookups (numbers, rules) |
| `python_virtual_environments.txt` | technical how-to questions |

## Example questions and where the answer should come from

| Question | Expected source |
|----------|-----------------|
| What does an inverter do in a solar system? | solar_energy_basics.txt |
| How often should solar panels be cleaned? | solar_energy_basics.txt |
| How many days of annual leave do employees get? | company_leave_policy.txt (18 days) |
| How many weeks of parental leave do primary caregivers receive? | company_leave_policy.txt (12 weeks) |
| How many days can I work from home each week? | company_leave_policy.txt (2 days) |
| How do I activate a virtual environment on Windows? | python_virtual_environments.txt |
| Should the .venv folder be committed to Git? | python_virtual_environments.txt (no) |

## Questions that should be refused (not in the documents)

| Question | Expected behaviour |
|----------|--------------------|
| Who is the prime minister of Canada? | "I couldn't find enough information..." |
| What is the company's salary for a senior engineer? | "I couldn't find enough information..." |

TXT files have no pages, so sources show only the filename. Page numbers appear
when you upload a PDF.
